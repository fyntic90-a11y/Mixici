# GUNER OS

Оболочка для Android (лаунчер + центр управления + настройки). Пакет `com.guner.os`, Android 10+ (API 29).
Kotlin, Jetpack Compose, Material 3, DataStore, MVVM.

## Как получить APK через GitHub
1. Создай репозиторий на GitHub и залей туда содержимое этой папки в ветку `main`.
2. Открой вкладку **Actions** → workflow **Build GUNER OS APK**. Сборка стартует на каждый push в `main`.
   Вручную: **Run workflow**.
3. Когда сборка зелёная, открой запуск и внизу в **Artifacts** скачай `GUNER-OS-debug-N` (или `release`).
4. Распакуй zip — внутри `.apk`.

## Установка на телефон
1. Перекинь APK на телефон и открой его.
2. Разреши установку из этого источника (Настройки → Безопасность → «Установка неизвестных приложений»).
3. Нажми «Домой» → выбери **GUNER Launcher** → «Всегда».
   Или: GUNER Настройки → Рабочий стол → «Сделать GUNER Launcher основным».
4. Для яркости и автоповорота в Центре управления выдай «Изменение системных настроек».
   Для управления музыкой включи «Доступ к уведомлениям» для GUNER OS.

Вернуть прежний лаунчер: Настройки Android → Приложения → Приложения по умолчанию → Главное приложение.

## Что уже работает (этапы 1–6 частично)
- Рабочий стол: страницы, сетка 4×5 / 5×5 / 5×6, док, меню по долгому нажатию, скрытие приложений, форма и размер иконок
- Панель приложений с поиском, жесты свайпа, анимации открытия, запуск-анимация, смена страниц
- Центр управления: Wi‑Fi, Bluetooth, моб. сеть, авиарежим, фонарик (реальный), автоповорот, экономия, яркость, громкость, музыка
- Настройки с сохранением (DataStore), режимы производительности, фирменные обои GUNER

## Ограничения (честно)
Обычный APK не может заменить системный экран блокировки, настоящий AOD при выключенном дисплее
и шторку уведомлений. Это требует прошивки или системных привилегий.
